# imunes-doc
IMUNES manual is available as a pdf book (IMUNES_manual.pdf) or a html page (IMUNES_manual.html + assets).

To make inside the `build` directory, install:

```
make
pandoc-cli
pandoc-crossref
texlive-basic
texlive-latex
texlive-xetex
texlive-latexextra
texlive-fontsrecommended
texlive-latexrecommended
```

Run:

```
# make clean

# make pdf
# make html
or
# make
```
