
#### [Interfaces tree (L2)](#interfaces-tree-l2)

Displays a list of 'physical' and logical interfaces. Select an interface to view its details and modify its settings.

Special items:

  * `Physical Interfaces` - Add or remove 'physical' (prefixed with `eth`) or stolen interfaces. Here, 'physical' refers to interfaces that are not logical, rather than interfaces that are non-virtual.

#### [Interfaces tree (L3)](#interfaces-tree-l3)

Displays a list of 'physical' and logical interfaces. Select an interface to view its details and modify its settings.

Special items:

  * `Physical Interfaces` - Add or remove 'physical' (prefixed with `eth`) or stolen interfaces. Here, 'physical' refers to interfaces that are not logical, rather than interfaces that are non-virtual.
  * `Logical Interfaces` - Add or remove dummy (prefixed with `lo`) or VLAN (prefixed with `vlan`) interfaces.
