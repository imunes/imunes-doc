
### [Understanding the Main Window](#understanding-the-main-window)

IMUNES main window is composed out of several components:

  * *Menu Bar* - Contains menus for controlling and manipulating various options regarding the GUI, currently opened topology and running experiment. The specific components of each menu in the menu bar are explained in more detail in documentation section [Menu Bar Reference](#menu-bar-reference).
  * *Canvas* - The main workspace where topology elements are created, positioned and connected. The canvas is explained in more detail in documentation sections [Working with IMUNES Canvas](#working-with-imunes-canvas) and [IMUNES Canvas Reference](#imunes-canvas-reference).
  * *Toolbar* - Contains all functional tools in the upper section and drawing tools in the lower section. The toolbox is explained in more detail in documentation section [Toolbox](#toolbox) and its specific elements in section [Toolbox Reference](#toolbox-reference).
  * *Status Bar* - Displays information about the current topology and experiment. The status bar is explained in more detail in documentation section [Status Bar Reference](#status-bar-reference)
  * *Topology Tree* - Hidden by default. Displays information about the current topology and experiment in *Tree View*. The topology tree view is explained in more detaial in documentation section [Topology Tree](#topology-tree).
