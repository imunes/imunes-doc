
### [Canvas Menu](#canvas-menu)

The *Canvas* menu contains options for canvas management [@fig:canvas_menu].

![Canvas menu](./assets/canvas_menu.png){#fig:canvas_menu width=20%}

  * *New* - Create a new canvas. Large topologies can be split across multiple canvases.
  * *Rename* - Change the name of the currently opened canvas.
  * *Delete* - Delete the current canvas and all elements placed on it.
  * *Resize* - Change the dimensions of the current canvas.
  * *Background image* - Configure the background image displayed on the current canvas.
  * *Previous* - Switch to the previous canvas.
  * *Next* - Switch to the next canvas.
  * *First* - Switch to the first canvas.
  * *Last* - Switch to the last canvas.
