
### [Edit Menu](#edit-menu)

The *Edit* menu([@fig:edit_menu]) contains options for handling elements on the canvas.

![Edit menu](./assets/edit_menu.png){#fig:edit_menu width=19%}

  * *Undo* - Revert the most recent topology modification.
  * *Redo* - Reapply the last reverted topology modification.
  * *Cut* - Remove selected nodes and links from the canvas and place them into the clipboard.
  * *Copy* - Copy selected nodes and links into the clipboard.
  * *Paste* - Insert nodes and links from the clipboard to the topology.
  * *Select all* - Select all nodes and annotations on the current canvas.
  * *Select adjacent* - Select all nodes directly connected to the currently selected nodes.
  * *Editor preferences* - Configure IMUNES default/custom/current global options.
