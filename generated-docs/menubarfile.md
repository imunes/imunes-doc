
### [File Menu](#file-menu)

The *File* menu([@fig:file_menu]) contains options for configuration files management.

![File menu](./assets/file_menu.png){#fig:file_menu width=20%}

  * *New* - Creates a new, empty IMUNES topology in `edit mode`.
  * *Open* - Open an existing IMUNES topology in `edit mode`.
  * *Recent files* - Show a list of recently opened files. It is possible to set a maximum number of these files to keep in a list using `recents_number` option.
    - *Pin current to 'Recent files'* - Pin the selected topology to the `Recent files` list.
    - *Remove current from 'Recent files'* - Remove the currently opened file from the `Recent files` list.
  * *Save* - Save the current topology to its existing file.
  * *Save As* - Save the current topology to a new file.
  * *Close* - Close the currently opened topology. Unsaved changes may prompt for confirmation.
  * *Print* - Print the currently displayed topology using the system print service.
  * *Print To File* - Export the current topology to a printable file format.
  * *Quit* - Exit IMUNES. You may be prompted to save unsaved changes.
