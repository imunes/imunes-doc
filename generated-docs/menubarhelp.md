
### [Help Menu](#help-menu)

When hovering over certain GUI elements, it is possible to get help for that element with the `F1` button on your keyboard. This will open a popup with explanations for that element.

![Help menu](./assets/help_menu.png){#fig:help_menu width=8%}

The *Help* menu has only one submenu.

  * *About* - Display version information, authorship and licensing details.
