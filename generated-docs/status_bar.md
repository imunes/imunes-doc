  * Canvas list scrollbar (1) - Use this to scroll through the list of available canvases.
  * Canvas list (2) - A list of created canvases. The currently selected canvas is marked using a different color.
    - Use left click to select the canvas, double click to rename it, or mouse-scroll to switch between different canvases.
    - Double-click on the empty part of this element creates a new canvas with the default name.
  * Canvas scrollbar (3) - Used to move left/right and up/down on the canvas, if the canvas is not fully visible.
  * Status line (4) - Used for various informational messages such as: current execution/termination step, node/link details, etc.
  * Zoom level (5) - Current zoom level. Double-click to insert custom zoom percentage value, or right-click to choose a pre-defined value.
  * Scheduler time (6) - Current step for event scheduler - time in seconds from the event scheduling start.
  * Auto-rearrange status (7) - Notifies user that either `Auto rearrange all` or `Auto rearrange selected` is enabled.
  * Operational mode (8) - Shows current mode of operation:
    - `edit mode` - the experiment is not executed, normal editing
    - `exec mode` - the experiment is executed
    - `pause mode` - the experiment is executed, but new elements will not trigger a runtime change
  * Experiment ID (9) - Shows the currently running experiment ID (EID) if the experiment is running.
